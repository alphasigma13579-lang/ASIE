## 4. خطة الإصلاح الجراحي وحد التوافق

قرار إعادة الاستخدام: استخدام Repository وSQLite والنماذج والصلاحيات والاختبارات القائمة؛ لا مكتبة أو اعتماد أو Runtime جديد.

1. **C-01:** تحقق valid_until عند كل استهلاك، بتوقيت واعٍ بالمنطقة ومقارنة وقت الاستهلاك. غياب القيمة أو نوع/صيغة غير صالحين أو وقت بلا منطقة أو منتهٍ/مساوٍ للحظة الحالية ⇒ رفض مغلق. إيصال مستقبلي صالح لا يتجاوز تحقق المؤسسة والمشروع والبصمة وإصدار العقد. لا Receipt جديد ولا تغيير Snapshot؛ لا يُنقل نجاح الحفظ إلى صلاحية دائمة.
2. **C-02:** قبل replay، تحقق شكل السجل واتساق هوية JSON مع الصف ونطاق المؤسسة والمشروع والحقول المدارة خادميًا، ثم دليل منشأ من المسار الخادمي المحدد في §4.1؛ ارفض الادعاءات غير المدعومة أو عدم الاتساق أو غياب الدليل بدل إعادتها أو تعديل الأصل بصمت. قائمة الحقول تستمد من مساري Draft والنموذج الأصليين، لا من القيم المخزنة نفسها.
3. **حد إثبات C-02:** تطابق JSON/الصف أو بادئة ctx أو timestamp أو علم trusted/internal أو بصمة محسوبة من مادة العميل لا يثبت المنشأ. سياسة الرفض حُسمت في §4.1؛ التفاصيل التنفيذية لترميز الدليل وربطه داخل التخزين القائم تحتاج تحققًا قبل الكود، وليست منفذة أو مختبرة هنا. لا schema/ترحيل أو حقل ثقة يقبله العميل؛ إذا تعذر الوفاء بالقائمة القائمة تُعرض توسعة قبل التنفيذ، لا يُستبدل الدليل بفحص شكل.
4. **C-03:** ارفض idempotency_key غير النصي أو الفارغ/المسافات في الحد الداخلي قبل lifecycle/fingerprint/insert؛ لا تحويل رقم أو dict إلى نص ولا تعديل عقد النموذج الأصلي. حافظ على الطلب الصحيح وإعادة الطلب المشروعة ضمن المؤسسة والمشروع.

المخاطر: الاستهلاك **عالي الأهمية الأمنية**، وأثر رفض الإيصالات القديمة وإعادة الطلب **متوسط التوافق**. الرسائل التشغيلية آمنة وفق EKB-08؛ لا تسرب payload أو تفاصيل استثناء أو معرفات داخل محتوى العميل. لا تدّعي حماية تاريخ السجلات بمجرد حماية الكتابات الجديدة.

### 4.1 سياسة C-02 المعتمدة للتوثيق — 2026-10-09

- القرار: [DECISION-FC20-12-F01A-REPLAY-ORIGIN-POLICY-2026-10-09](https://github.com/alphasigma13579-lang/ASIE/pull/193#issuecomment-6080187374)، موضوعه رأس الملحق `a9cd8bdcfe1b81e7a51d8eb27d4623a61c2e1609` والتوصية في المحادثة؛ المالك قال «اعتمد». أثره **POLICY_DOCUMENTATION_APPROVED_ONLY**: تثبيت السياسة والاختبارات المطلوبة، لا دمج أو تسجيل نطاق أو استئناف تطبيق. وقت تسجيل الإيصال محفوظ فيه؛ ليس إثبات هوية مشفرًا.
- الإنشاء الجديد يحفظ السجل ودليل منشئه الخادمي في **المعاملة المحلية نفسها**. يعاد استخدام تخزين التدقيق القائم `security_audit_events`، دون جدول أو schema أو مخزن ثانٍ. لا تستعمل `Repository.audit()` كما هي داخل المعاملة: فهي تفتح اتصالًا وتنفذ commit مستقلًا؛ المطلوب كتابة الدليل من اتصال المعاملة نفسه كي لا ينفصل عن السجل أو يتعطل بقفل كتابة.
- الدليل يُكتب فقط من مسار خادمي معلوم، ويربط هوية السجل بالمؤسسة والمشروع ومسار الإنشاء وإصدار السياسة وبصمة هوية الإنشاء الثابتة المناسبة، لا حقولًا متغيرة مثل updated_at أو إصدار Draft بعد تحديث CAS. لا يُنشأ الدليل من قراءة أو replay أو update لسجل سابق. الصيغة الدقيقة تثبت قبل الكود؛ لا تستمد من payload أو correlation_id يختاره العميل، ولا يعوضه حدث السماح القديم `aia.context.create` وحده لأنه كان موجودًا في المسار السابق.
- يُميّز دليل Draft ذي المعرف المولّد خادميًا عن دليل حفظ النموذج الداخلي المتحقق؛ لا تدّعي أن معرف النموذج الداخلي ولّده الخادم لمجرد تحقق lifecycle. لا يضيف الدليل Review/ApprovalReceipt ولا يجيز Run أو Finance أو Snapshot؛ هو دليل منشأ محلي ضمن حد الثقة في قاعدة التطبيق، **ليس توقيعًا تشفيريًا** ولا حماية من تعديل قاعدة البيانات بامتياز مباشر.
- عند replay، يُقرأ الدليل داخل حدود المؤسسة والمشروع وتتحقق علاقته بالسجل ومسار إنشائه؛ الدليل الناقص أو المختلف أو غير المدعوم ⇒ رفض مغلق قبل رد نتيجة السجل أو ادعاءات الثقة. لا تغيير للهوية أو إعادة اعتماد أو حذف أو تصحيح صامت.
- السجلات القديمة، بما فيها مسودات أنشئت قبل هذا الإصلاح ولم يثبت منشؤها بهذا المسار، لا تحصل على دليل بأثر رجعي. قد يحتاج المستخدم إلى إنشاء مسودة جديدة بمفتاح طلب جديد عبر المسار القائم؛ لا زر أو واجهة جديدة هنا ولا تعديل تلقائي لقاعدة المالك. تُحفظ السجلات للقراءة المصرح بها حسب عقدها، ولا يصبح وجودها دليل اعتماد أو صلاحية replay.
- إعادة الطلب المشروعة للسجلات الجديدة المثبتة تبقى idempotent: نفس النتيجة دون سجل/دليل إنشاء مكرر؛ محاولتان متزامنتان لا تتركان سجلًا أو دليلًا يتيمًا. يُحافظ على مسار النموذج الداخلي المتحقق مع دليل مساره الصحيح، لا باستثناء عام للسجلات القديمة.
- **حالة التنفيذ:** NOT_IMPLEMENTED / TESTS_NOT_RUN. شروط السياسة أدناه لا تعني تحققها. ملف التطبيق أو الحارس أو السجل الحاكم لم يتغير؛ يلزم تسجيل النطاق والاستئناف المراجعان قبل كودهما.
