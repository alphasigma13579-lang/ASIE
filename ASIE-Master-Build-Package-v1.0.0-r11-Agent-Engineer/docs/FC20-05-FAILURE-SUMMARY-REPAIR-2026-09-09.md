# F05-02 — تنقيح ملخصات فشل المعرفة الاقتصادية

## الخطة والحدود

- المصدر: GitHub الرسمي؛ أساس التنفيذ `70331cdbd24daf22bfd9ab4a9c5252d39eccb661`.
- العيب: `PublicKnowledgeSync.run` و`main` ينسخان نص الاستثناء واسم صنفه إلى JSON، ويضيف CLI ادعاء `secrets_exposed=False` غير مثبت.
- النطاق: ملخصات الاستثناء في المزامنة وCLI فقط؛ لا تغيير للمخزن أو السجل أو العميل الخارجي أو الصلاحيات أو Finance أو Snapshot أو AAS أو Decision Council.
- القبول: اختبار علامة حساسة في الاستثناء وصنفه وسببه؛ غيابها من ملخص المزامنة وstdout/stderr، مع حالات تشغيل وتعافٍ ثابتة، وفحوص مناسبة ومراجعة الرأس نفسه.
- نقطة التوقف: PR قابل للمراجعة؛ لا دمج أو نشر أو تشغيل مزود.

## الإصلاح

`_safe_failure` ينشئ وصفًا من رموز مملوكة مطابقة تمامًا أو تصنيف تشغيل ثابت. لا ينسخ اسم صنف الاستثناء أو رسالته أو سببه أو traceback، ولا يستخدم بادئات لقبول نص حر. أخطاء التعويض غير المكتمل تحتفظ برمزها وتطلب إيقاف إعادة المحاولة ومراجعة الاتساق.

حقلا `reason` و`error_type` محفوظان بمدخلات ثابتة؛ أضيف `message` و`next_action` بالعربية لوصف الحالة والتعافي. هذه مخرجات تشغيلية وليست عقد عرض عميل جديدًا؛ لا يُعرض التشخيص التقني للعميل. أزيل ادعاء `secrets_exposed` من فشل CLI؛ الاختبارات دليل محدود لحدود الاستثناء، وليست شهادة خلو جميع محتويات المعرفة من الأسرار.

لا تغير هذه الشريحة التعويض أو إعادة الفهرسة أو الحفظ. الأخطاء غير المعروفة لا تقترح تجاوز الصلاحيات أو إعادة محاولة غير محدودة. يبقى مصدر التتبع هو المصدر المسجل وحالة التشغيل دون تفاصيل استثناء خام.

## التحقق

تضيف اختبارات المصدر extract/crawl/upsert، وحماية dry-run، وفشل التحميل/الإنشاء/التشغيل/إعادة الفهرسة في CLI، وملخص CLI المتداخل، والرموز المجهولة أو المشابهة، والتحويل النصي غير الموثوق، وأخطاء التعويض غير المكتمل. النتائج الفعلية والمراجعات تسجل في PR على رأسه النهائي؛ لا تعد هذه الوثيقة إعلان نجاح مسبق.

تشمل بوابات الرأس النهائي اختبارات FC20-05 القائمة للصلاحيات والعزل والتعويض وسلامة البيانات، مع CI الكامل وفحوص التجميد القائمة. لا يشغّل workflow المزامنة الحية، ولا يضاف مزود أو سر.

## معالجة مراجعة Copilot

ثبتت ملاحظة المراجعة 3968028970 على الرأس 7ffdd2b: كان معالج المصدر يستدعي التحويل النصي قبل وصوله إلى التنقيح، مما يسمح لاستثناء فرعي ذي تحويل نصي فاشل بالخروج من المزامنة. يحسب الإصلاح نتيجة التنقيح مرة واحدة ويستخدم رمزها الثابت للتعويض والعزل والملخص. رموز عدم مطابقة العنوان المملوكة تبقى أسباب عزل؛ الأصناف الفرعية لا تنتحلها.

وُسعت اختبارات extract/crawl/upsert وdry-run ومخرج CLI المتداخل باستثناء فرعي يفشل تحويله النصي، وأضيف رفض انتحال رموز العزل والتعويض. تبقى اختبارات العزل والتعويض الحالية بوابات عدم تراجع. النتائج لا تُعد ناجحة قبل CI على الرأس الجديد.

## مراجعة المدخل المتوافق ومعاملات الاستثناء

ملاحظة 3968291333 صحيحة: مدخل التشغيل المتوافق vision2030_kb_sync كان يعيد نص الاستثناء الخام. أصبح يعيد نتيجة المنقح نفسه دون تغيير التفويض أو الحفظ؛ تغطي الاختبارات فشل قراءة السجل وإنشاء الخدمة وتشغيلها.
