# EKB Domains Index

## AAS

- `AAS-Runtime-Freeze`: يحكم الملفات والمسار المجمد.
- `Snapshot-Assembly`: يحكم اللقطة غير القابلة للتلاعب.

## AIA

- `AIA-Intelligence-Architecture`: الذكاء كطبقة مكملة لا Runtime ثانٍ.
- `Sanad-Product-AI-Experience`: تجربة Sanad ومقابلة المستخدم دون امتلاك الأرقام.

## DIB

- `Dynamic-Input-Blueprint`: نقطة التقاء مسار الفكرة ومسار البيانات.
- `Product-Project-Profile`: تعريف فكرة المشروع والموقع والقطاع.
- `Product-AI-Interview`: مقابلة موجهة لا تولد أرقامًا نهائية.
- `Template-Registry`: قوالب الاحتياجات والبنود.
- `Question-Registry`: أسئلة محكومة حسب القالب.
- `Data-Intake`: Manual/CSV/XLSX/PDF-text.
- `PDF-Intake-Document-AI-Quote-Extraction`: استخراج نصوص وعروض أسعار وربطها بالبند.
- `Template-Matching`: مطابقة الملف مع البنود.

- `Finance-Engine`: الحسابات المالية والحساسية وMonte Carlo.
- `Monte-Carlo-and-Sensitivity`: منطق MC والبوابات.
- `Market-Estimation-Engine`: P25/P75/Weighted Median.
- `Market-Intelligence`: منافسون ومقارنات وسوق.
- `National-Economic-Intelligence`: مؤشرات الاقتصاد المحلي.
- `Economic-Opportunity-Intelligence`: بيانات دولية وفرص اقتصادية.
- `Strategic-Alignment-Score`: توافق استراتيجي ورؤية 2030.
- `KPI-Intelligence-Engine`: مؤشرات الأداء.
- `Decision-Council`: مجلس القرار.
- `Risk-Engine`: المخاطر.
- `Execution-Engine`: خطة التنفيذ.
- `Evidence-Ledger`: الأدلة.
- [`Tavily-Governed-Source-Admission`](Tavily-Governed-Source-Admission.md): بحث اكتشافي مقيد، وموافقة خادمية إلزامية قبل extract/crawl/map.
