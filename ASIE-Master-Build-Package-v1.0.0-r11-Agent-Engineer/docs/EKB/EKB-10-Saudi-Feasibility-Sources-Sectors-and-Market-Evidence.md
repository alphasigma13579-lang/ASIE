## 1. الخدمة الأساسية والخدمات الداعمة

الخدمة الأساسية هي **دراسة جدوى المشروع**. البحث الاقتصادي والسوقي، الخرائط والمنافسون، أسعار المعدات والخدمات والإيجارات، تحسين الفكرة، اكتشاف فرص بديلة، والإرشاد إلى برامج الدعم خدمات داعمة للدراسة وليست منتجًا منفصلًا بديلًا عنها.

يقرأ الوكيل هذا الملف قبل أي عمل ضمن نطاقه، ثم العقد والمكوّن المتأثر. لا يكرر قائمة المصادر داخل البرومبت ولا يفترض أن الوثيقة سجل تشغيل آلي.

متطلبات المالك في هذا المرجع توسّع **نطاق الحصر والتطوير المطلوب**، ولا تتجاوز [AIA-01](../AIA-01-Intelligence-Constitution-v1.0.0.md) أو [AIA-02، خصوصًا الأقسام 13 و15–17](../AIA-02-Intelligence-Operating-Architecture-v1.2.1.md) أو ACRs أو سجل المصادر الحالي أو بوابات التشغيل. تصنيف مصدر بأنه غير مفعّل داخل ASIE لا يعني أن ناشره يمنع استعماله.

أي تعارض مع قيد قائم يسجل مع مصدره، ويعالَج بتغيير حاكم مستقل عند الحاجة؛ لا تعدّل القيد أو توسّع الجلب ضمن عمل توثيقي.

## 3. فصل الاكتشاف عن الجلب وعن الاعتماد

1. **سجل الحصر:** واسع، يشمل الرسمي والخاص والأخبار والأسواق.
2. **الاكتشاف:** وفق سياسة البحث الخادمية المعتمدة؛ لا يوسّع المتصفح النطاقات.
3. **الجلب والاستخراج:** لكل مصدر عملية وطريقة محددتان: API أو ملف مفتوح أو تغذية مرخصة أو شراكة أو استخراج محدود مصرح. لا نفترض أن الزحف الشامل هو الوسيلة الوحيدة.
4. **الحفظ والاسترجاع:** وفق حقوق المحتوى والاحتفاظ والحذف وعزل المستأجرين.
5. **الاستعمال المالي:** دليل منقح ومربوط بالبند، اعتماد الافتراض ثم مسار DIB المعتمد؛ ليس اعتماد المصدر وحده.

سجل التشغيل المالك حاليًا يختلف حسب المسار:
- [قبول Tavily](domains/Tavily-Governed-Source-Admission.md): سجل backend/source_registry.py وقرار القبول الخادمي.
- [المعرفة الاقتصادية العامة](domains/Public-Economic-Knowledge.md): config/public_knowledge_sources.json والعقد الخاص به.
لا تُدخل أسعار الأسواق أو عروض العملاء في corpus الاقتصاد العام لمجرد أنها معلومات منشورة. إضافة موصل تجاري أو تغيير سياسة مصدر يحتاج المسار الحاكم المناسب، لا تعديلًا صامتًا لسجل رسمي مفتوح.

## 4. قطاعات «ابدأ مشروعك»

واجهة مبسطة: **القطاع العام ← النشاط الفرعي ← النشاط الدقيق ← وصف الفكرة**.
تربط الأنشطة داخليًا بالتصنيف الوطني للأنشطة الاقتصادية وإصداره؛ لا نخترع أكوادًا. [مرجع وزارة التجارة](https://mc.gov.sa/ISIC4/Documents/%28ISIC4%29.pdf).

مجموعات العرض التالية متطلبات UX مقترحة، وليست نقلًا حرفيًا لأقسام التصنيف الرسمي أو قائمة تراخيص:
1. الزراعة والثروة الحيوانية والسمكية.
2. التعدين والمحاجر.
3. الصناعة والتصنيع.
4. الطاقة والمرافق.
5. البيئة وإدارة النفايات.
6. البناء والمقاولات.
7. التجارة والجملة والتجزئة.
8. النقل والتخزين والخدمات اللوجستية.
9. المطاعم والمقاهي وخدمات الطعام.
10. السياحة والضيافة والسفر.

حقل وصف الفكرة لا يستبدل النشاط الدقيق. يقترح المساعد تصنيفًا عند الحيرة، ويؤكده المستخدم. لا يحوّل نشاطًا مخصصًا غير معروف إلى أول نشاط افتراضي بصمت. تغير التصنيف يعيد تقييم ملاءمة الأدلة ولا يحذف مشروع المستخدم.

التجارة الإلكترونية قناة تشغيل غالبًا، والذكاء الاصطناعي تقنية محتملة، وغير الربحي صفة كيان؛ لا تُعامل آليًا كبدائل لتصنيف النشاط. تحفظ القناة حضوري/إلكتروني/متنقل/هجين منفصلة. نشاط رئيسي وأنشطة ثانوية ممكنة دون عد مزدوج. اختيارات الموقع والقطاع المعتمدة تؤخذ من المشروع المحفوظ مع تحقق الملكية.

## 5. أدلة الأسعار والمواصفات

قبل البحث يحدد البند المطلوب: الوظيفة، السعة، المواصفات، فئة الاستخدام المنزلي/التجاري/الصناعي، الكمية، الجديد أو المستعمل، والموقع المطلوب للتسليم.

لكل مشاهدة سعر تسجل:
- رابط المصدر والناشر والبائع ووقت الرصد، والموديل/المواصفات والكمية والوحدة.
- العملة والأساس الضريبي والتوافر ومدة صلاحية العرض عند وجودها.
- جديد/مستعمل، جملة/تجزئة، الحد الأدنى للطلب، الضمان وخدمة ما بعد البيع.
- الشحن والتأمين والرسوم والجمارك والتركيب والتدريب والتشغيل الأولي: مشمول/غير مشمول/غير معلوم.
- سعر الإعلان منفصل عن تكلفة الوصول وتكلفة التركيب والجاهزية التشغيلية.
- للمستورد: بلد المنشأ والتسليم وشروط التجارة عند توفرها؛ لا يعرض سعر بلد آخر كتكلفة سعودية.
- للإيجار: الموقع والمساحة والاستعمال والحالة، شهري/سنوي، التأمين والخدمات والعمولة والتجهيز، سعر طلب مقابل عقد/صفقة.

المفقود ليس صفرًا. لا تختَر الأرخص تلقائيًا ولا تخلط منتجات غير متجانسة أو تكرر عرض البائع عبر أكثر من منصة. نطاقات الأسعار تحتاج عينة موثقة وأوزانًا ومنهجية مالكة؛ الإعلان المنفرد مؤشر أولي لا متوسط سوق.

أي تحويل إلى تكلفة دراسة يمر بـ **تحقق الدليل ← تطبيع ومطابقة البند ← مراجعة وقبول المستخدم ← Approved Input Manifest ← المسار المالي الحاكم**. لا اتصال مباشر من الزحف أو AI إلى Finance.

## 6. الخرائط والمنافسة واتجاه السوق

- GPS بموافقة، أو عنوان/دبوس يدوي؛ لا حفظ للموقع الخام قبل تأكيده كموقع المشروع.
- الخرائط وPlaces مسار مصرح مستقل؛ لا زحف Google Maps ولا تخزين Places في Pinecone من هذه الوثيقة.
- تعرض منشآت مشابهة/منافسين محتملين حسب النشاط والموقع، مع مصدر وتاريخ ونطاق البحث ومسافة موضحة النوع.
- عدد نتائج الخريطة ليس تعدادًا شاملًا ولا حجم سوق؛ غياب النتائج لا يثبت غياب المنافسة.
- قرب المنشأة لا يثبت أنها منافس مباشر؛ تراعى الخدمة والعملاء والقناة والنطاق الجغرافي.
- اتجاه السوق يحتاج مؤشرات زمنية قابلة للمقارنة؛ الخبر الواحد إشارة لا إثبات نمو أو طلب أو إيراد.

## 7. تطوير الفكرة والبدائل وسند

يجوز عرض تحسين أو نشاط بديل أو موقع بديل كفرضية مدعومة. توضح المقارنة: الأدلة، متطلبات رأس المال والمهارات والوقت والموقع، المخاطر، التكاليف الناقصة وحدود الثقة. لا يقال «أفضل من مشروعك» حكمًا مطلقًا؛ يذكر المعيار والافتراضات، ويترك القرار للمستخدم. يحتفظ بالمشروع الأصلي وتُنشأ مسودة بديلة فقط بموافقته. أي مقارنة مالية تحتاج دراستين بالمسار الحاكم لا أرقام AI.

سند واجهة إرشاد: يشرح، يقود للحقل/الدليل/الخريطة/العرض المناسب، ويعيد المستخدم لموضعه. ليس مالك الجلب أو الأسعار أو القرار. لا يضاف مزود أو قدرة خلفية باسم سند دون عقدها. [EKB-08](EKB-08-Customer-Language-and-Presentation-Contract.md) يحكم العربية والإنجليزية وإخفاء التشخيصات.

## 8. سجل كل مصدر وربطه بالمستهلك

لكل ناشر/مسار: معرف داخلي، الفئة، URL، الجهة المالكة، القطاعات/الأنشطة، الجغرافيا، نوع الأدلة، المستهلكون، طريقة الوصول، حالة الاكتشاف/الجلب/الحفظ/إعادة العرض كل على حدة، الشروط ودليلها وتاريخ مراجعتها، الإسناد، حداثة البيانات، الاحتفاظ والحذف، المراجع والموافقات، سبب المنع إن وجد ونقطة إعادة المراجعة.

الموثوقية ليست درجة واحدة: هوية الناشر لا تثبت صحة كل ادعاء أو تطابق مواصفات السعر. القيم التقنية للمشرف فقط؛ العميل يرى المصدر والتاريخ والمعنى والحدود والخطوة التالية.

## 9. قبول التنفيذ اللاحق

- إثبات التصنيف الوطني ومطابقة النشاط دون fallback صامت.
- اختبار مصادر وأسعار حقيقية مأذونة؛ لا بيانات وهمية بوصفها سوقًا حيًا.
- اختبار الوحدات والعملات والضريبة والشحن والتكرار والحداثة وتعارض الأسعار.
- اختبارات الصلاحيات والعزل وحقن التعليمات وإيقاف الجلب والحدود والكلفة عندما يمسها التغيير.
- عدم خلط corpus العام بعروض المشروع أو بيانات Places.
- سند يوجه إلى الإجراء الصحيح دون أن يعتمد افتراضًا أو يغير نتيجة.
- التقارير تعرض جودة الدليل والنقص ولا تعد بتمويل أو نجاح.
- لا يغلق أي بند بمجرد إضافة اسم مصدر؛ يثبت كود واختبار وربط فعلي للمستهلك.
