# قاعدة المعرفة الهندسية ASIE — EKB

هذه هي نقطة الدخول العربية الرسمية إلى **ASIE Engineering Knowledge Base — EKB**.

الغرض من EKB هو منع تضخم البرومبتات، ومنع ضياع المعرفة بين المحادثات، وتحديد أين توضع كل معلومة هندسية داخل مشروع **AlphaSigma Intelligence Engine — ASIE**.

## ما لا يدخل البرومبت

لا توضع التفاصيل طويلة الأجل داخل البرومبت، مثل:

- قواعد AAS Runtime Freeze.
- تفاصيل DIB.
- محركات السوق والماليات والقرار.
- قواعد Monte Carlo.
- وثائق National Economic Intelligence.
- Strategic Alignment Score.
- سياسات PDF Intake وQuote Extraction.
- خرائط Dashboard وLaunch Guide.

مكانها الصحيح داخل EKB أو الوثائق الحاكمة.
