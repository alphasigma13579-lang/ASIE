# EKB-08 — سجل قبول أسطح العميل

الحالة: سجل قبول تابع للعقد الحاكم EKB-08  
النطاق: واجهات العميل والتقارير فقط؛ لا يغيّر Finance أو Snapshot أو AAS أو Decision Council.

## قاعدة القبول

لا تعد كلمة أو مسمى أو حالة مقبولة لمجرد أنها مخفية في لقطة شاشة. يجب أن يثبت كل سطح:

1. العربية الكاملة عند اختيار العربية، والإنجليزية الكاملة عند اختيار الإنجليزية.
2. عدم ظهور المعرفات أو التجزئات أو أسماء العقود والمحركات والحالات البرمجية.
3. وجود معنى أعمال واضح، وحدود النتيجة، والخطوة التالية عند الحاجة.
4. عمل التنقل بلوحة المفاتيح وعلى الهاتف وسطح المكتب.
5. مراجعة بصرية بشرية مستقلة قبل الإغلاق النهائي.

## أسطح مستبعدة من واجهة العميل

- لوحة المشرف وسجل التدقيق: متاحة فقط لصلاحية `platform_admin`.
- مسارات DIB والهندسة: خلف بوابة الصلاحية الإدارية ولا تعد أسطح عميل.
- البيانات الأصلية والعقود والمعرفات تبقى خادمية لأغراض التدقيق ولا تعرض للعميل.

## الاستثناءات المسموحة

- العلامة التجارية ASIE.
- أسماء صيغ الملفات PDF وDOCX وPPTX.
- الاختصارات المالية الضرورية مثل NPV وIRR وDSCR بعد شرحها عند أول ظهور.
- اسم المصدر الأصلي أو اقتباسه عندما يعرّف بوضوح بأنه نص مصدر.

## حالة الإغلاق

الاختبارات الآلية المذكورة موجودة، لكن الإغلاق النهائي للعقد **غير مكتمل** حتى تنجح المراجعة البصرية البشرية المستقلة بالعربية والإنجليزية على الهاتف وسطح المكتب، وتوثق نتيجتها على الرأس نفسه.
